# Game Idea: Orbit Dodge

A minimalist HTML canvas game where the player rotates a ship around a central planet to dodge incoming asteroids. The ship can move clockwise or counter‑clockwise using arrow keys or touch. The player loses if the ship collides with an asteroid or runs out of fuel (fuel depletes over time). Score is based on survival time.
