Added audio feedback:

* **Beep** on asteroid spawn, scoring, and collision.
* Created an `AudioContext` and a reusable `beep(freq, duration)` helper.
* Resumes the audio context on the first user interaction (keyboard or mouse).  

All sounds are generated programmatically, no external assets required. The game now plays short tones for key events while still targeting the canvas with `id="game"`.
