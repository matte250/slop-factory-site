Implemented **Asteroid Dodge** in `game.js`. The script targets the canvas with `id="game"` and provides:

- Ship control via arrow keys or mouse movement  
- Falling asteroids that increase in speed and spawn rate over time  
- Collision detection and game‑over handling  
- Score tracking and display  

Add `<canvas id="game"></canvas>` to your HTML and include this script to run the game.
