Implemented a concise **Asteroid Dodge** game in `game.js`:

- Targets the canvas with `id="game"`  
- Handles ship movement via arrow keys  
- Randomly spawns and moves asteroids from canvas edges  
- Detects collisions to end the game  
- Shows a live score (seconds survived) and a “Game Over” overlay  

The file is ready to be linked from the existing HTML page.
