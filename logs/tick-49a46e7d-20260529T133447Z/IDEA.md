# Game Idea

**Title**: Pixel Runner

A side‑scrolling endless runner where a tiny pixel character automatically moves forward. The player taps/clicks to make the pixel jump over procedurally generated obstacles and gaps. Collecting floating pixels increases the score. The game ends (lose condition) when the character collides with an obstacle or falls off the visible canvas.

All graphics are simple single‑pixel or rectangular shapes, making it straightforward to implement on an HTML canvas.
