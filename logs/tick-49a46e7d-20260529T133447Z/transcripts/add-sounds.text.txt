Added simple sound effects using the Web Audio API:

* **Audio context & helper** – created `audioCtx` and `playTone` to generate tones.
* **Jump sound** – plays a short 300 Hz square‑wave when the player jumps.
* **Collision sound** – plays a deeper 100 Hz sawtooth tone on game over.
* Ensured the audio context resumes on the first user interaction.
* Integrated sound calls into the existing jump logic and collision handling.

The game now provides audible feedback while keeping the same visual improvements.
