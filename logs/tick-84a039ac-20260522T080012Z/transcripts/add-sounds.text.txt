Added sound effects using the Web Audio API:

* Created an `AudioContext` and helper functions to play tones for thrust, explosions, and fuel pickups.  
* Integrated thrust sounds on any movement key press.  
* Triggered an explosion sound when the ship collides with an asteroid.  
* Added a placeholder `playFuel` (ready for future use with fuel pickups).

All audio logic lives in `game.js`, which still targets the existing `<canvas id="game">`. The game now has audible feedback for player actions and collisions.
