Implemented richer graphics for the Shrink Maze game:

* Added dark‑to‑blue background gradient.
* Applied shadow blur to all renderings.
* Rendered maze walls with a gradient stroke.
* Created twinkling stars using per‑frame alpha modulation and radial gradients.
* Switched enemies to rotating red triangles.
* Gave the player a blue radial gradient.
* Introduced a `frame` counter to animate the stars.

All changes are in **game.js**, targeting the existing `<canvas id="game">`. The game now has a more polished visual style while preserving the original mechanics.
