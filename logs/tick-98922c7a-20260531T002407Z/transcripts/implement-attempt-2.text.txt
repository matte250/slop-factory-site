The **`game.js`** file has been created and implements a simple “Space Escape” arcade runner:

* Targets the `<canvas id="game">` element.
* Handles player movement with arrow keys.
* Spawns and moves asteroids.
* Detects collisions, ends the game, and resets.
* Tracks and displays the score based on survival time and asteroids dodged.

You can now include this script in your HTML page to run the game.
