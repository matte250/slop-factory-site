# Game Idea: Space Debris Dodge

- **Genre:** Endless runner / dodge
- **Controls:** Arrow keys (or WASD) to move a small ship on the canvas.
- **Goal:** Survive as long as possible by avoiding randomly generated debris that flies in from the edges.
- **Mechanic:** Debris spawns at random intervals and speeds; the ship can accelerate in four directions but has limited inertia.
- **Lose Condition:** The ship collides with any debris or moves outside the canvas bounds, ending the game.
- **Visuals:** Simple shapes (triangle for ship, circles for debris) drawn on an HTML `<canvas>`.
- **Scoring:** Distance survived or time elapsed, displayed on-screen.
