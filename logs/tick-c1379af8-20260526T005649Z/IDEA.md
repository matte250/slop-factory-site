# Game Idea

**Title:** "Pixel Runner"

**Concept:** A side‑scrolling endless runner where the player controls a pixelated character that automatically runs forward. The player taps/clicks to make the character jump over obstacles (spikes, gaps, moving blocks) that appear on the canvas.

**Controls:** Single tap or space bar to jump. Holding the key extends the jump height.

**Goal:** Survive as long as possible while accumulating points for each obstacle passed.

**Lose Condition:** Colliding with an obstacle or falling into a gap ends the game.

**Visuals:** Minimalist 2‑pixel‑wide sprites on a dark background, using HTML canvas for rendering and simple physics.

**Why Feasible:** Implementable with vanilla JavaScript, HTML canvas drawing, requestAnimationFrame loop, and basic collision detection. No external assets required.
