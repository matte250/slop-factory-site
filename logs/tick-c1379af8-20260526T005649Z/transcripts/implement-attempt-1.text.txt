Implemented **Pixel Runner** – a minimal endless‑runner game in `game.js` that targets the existing `<canvas id="game">`. The script:

* Sets up canvas size and drawing context.  
* Defines player physics (gravity, jump, ground detection).  
* Spawns simple square obstacles at regular intervals, moves them left, and removes them when off‑screen (incrementing score).  
* Handles collision detection to end the game.  
* Renders the background, player, obstacles, and score each frame via `requestAnimationFrame`.  
* Adds keyboard (Space) and mouse/touch input for jumping.

Include the script in the HTML page to activate the game.
