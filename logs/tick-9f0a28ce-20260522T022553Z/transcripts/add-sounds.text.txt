Added simple sound effects using the Web Audio API:

* Created an `audioCtx` and helper `playTone` to generate tones.
* Added `playJumpSound` (high‑pitched tone) triggered on player jump.
* Added `playGameOverSound` (low‑pitched tone) triggered on collision.
* Integrated these calls into the jump logic and game‑over condition.

All changes are in **game.js**, which still targets the canvas element with `id="game"`.
