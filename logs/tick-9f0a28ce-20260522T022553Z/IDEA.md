# Game Idea: Canvas Runner

A side‑scrolling endless runner drawn on an HTML canvas. The player controls a simple shape that can jump to avoid procedurally generated obstacles (spikes, gaps, moving blocks). The canvas scrolls continuously, increasing speed over time. **Lose condition:** the player collides with an obstacle or falls off the platform.

The game can be built with vanilla JavaScript, using requestAnimationFrame for smooth animation and basic collision detection.
