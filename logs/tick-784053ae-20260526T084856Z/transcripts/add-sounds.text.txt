Added audio effects:

* **Engine thrust** – a short 440 Hz beep each time the up‑thrust key is pressed.  
* **Asteroid spawn** – a brief 300 Hz ping whenever a new asteroid appears.  
* **Collision / Game Over** – a lower 200 Hz beep when the ship hits an asteroid.  

Implemented with the Web Audio API, initializing an `AudioContext`, resuming it on the first interaction, and using a reusable `playBeep(freq, duration)` helper. The game now provides immediate auditory feedback for key actions without affecting the existing gameplay logic.
