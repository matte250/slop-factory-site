# Asteroid Escape

- **Genre:** Arcade/Survival
- **Controls:** Move ship left/right with arrow keys or A/D.
- **Gameplay:** Asteroids fall from the top of the canvas at increasing speed. The player must dodge them; collision ends the game.
- **Win Condition:** Survive as long as possible, earning points over time.
- **Lose Condition:** An asteroid collides with the ship.
- **Implementation Notes:** Simple sprite drawing, basic physics for gravity, collision detection, and a score timer can be handled entirely with the HTML canvas API.
