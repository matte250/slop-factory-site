# Game Idea: **Orb Runner**

- **Genre:** Endless runner / arcade
- **Controls:** Arrow keys (←/→ to rotate ship, ↑ to thrust)
- **Goal:** Keep the ship moving forward through an infinite starfield, avoid obstacles, and survive as long as possible.
- **Obstacles:** Randomly spawned asteroids and laser barriers that move toward the player.
- **Power‑ups:** Temporary shields or speed boosts appear occasionally.
- **Lose Condition:** Colliding with any obstacle (asteroid or laser) ends the game.
- **Implementation:** All visuals rendered on an HTML5 `<canvas>` using simple 2‑D physics and sprite drawing.

*The game fits within a single HTML page with a canvas element and can be built with plain JavaScript.*
