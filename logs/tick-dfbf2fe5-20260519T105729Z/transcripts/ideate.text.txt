# Game Idea

**Title:** Asteroid Sprint  
**Genre:** Endless runner / survival  

**Core mechanics:**  
- Player pilots a ship scrolling across a starfield.  
- Tap/press to thrust upward; gravity pulls down.  
- Random asteroids appear from the right; dodge them.  
- Collect fuel cells to extend time.

**Lose condition:**  
- Collision with any asteroid ends the game instantly.

**Why it fits HTML canvas:**  
- Simple 2‑D shapes and distance‑based collision detection can be rendered with the canvas API, requiring no external assets.  

**Optional extensions:** power‑ups, speed increase, local‑storage leaderboard.
