# Game Idea: Canvas Dash

- **Genre**: Endless runner
- **Core loop**: A small circle moves automatically to the right across a procedurally generated terrain. Press space (or tap) to jump over gaps and obstacles.
- **Lose condition**: Colliding with an obstacle or falling into a gap ends the game.
- **Scoring**: Collect floating stars and increase distance traveled.
- **Implementation**: Simple 2D rendering and collision detection using the HTML `<canvas>` element; no external assets required.
