# Game Idea: Canvas Dodger

**Concept**: Control a small ship that moves horizontally across the bottom of the canvas. Meteors fall from the top at random positions and speeds.

**Goal**: Survive as long as possible by dodging the meteors.

**Lose Condition**: The ship collides with any meteor.

**Key Mechanics**:
- Arrow keys (or mouse) to move left/right.
- Meteors spawn continuously, increasing in speed over time.
- Simple score based on survival time.

**Why Canvas?**: All graphics are drawn with primitive shapes (rectangles, circles) on the HTML5 canvas, requiring only basic animation loops.
