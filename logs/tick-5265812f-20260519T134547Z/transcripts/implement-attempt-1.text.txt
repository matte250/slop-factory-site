Implemented **`game.js`** with a concise Asteroid Escape game:

- Targets canvas `id="game"`
- Handles ship controls (click‑thrust, mouse steering)
- Spawns, moves, and removes asteroids
- Detects collisions, manages health, and shows a game‑over screen
- Adjusts canvas size, draws ship, asteroids, health bar, and overlay

Add this script to the HTML page that contains the `<canvas id="game">` element to run the game.
