# Game Idea: Orbital Escape

A top‑down HTML canvas game where the player pilots a ship through an ever‑growing field of rotating asteroids. Use arrow keys (or mouse) to thrust and steer. The game ends (lose condition) when the ship collides with any asteroid. Score is based on time survived.
