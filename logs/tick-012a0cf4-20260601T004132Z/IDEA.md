# Game Idea: Neon Escape

**Genre:** Arcade / Endless Runner
**Platform:** HTML Canvas

**Concept**
- The player pilots a small ship navigating an endless, scrolling neon tunnel.
- Obstacles appear as glowing barriers that must be dodged.
- Controls: left/right arrow keys to steer, spacebar for a short boost.

**Goal**
- Survive as long as possible while the tunnel speeds up.
- Score accumulates by distance traveled.

**Lose condition**
- Collision with an obstacle.
- Running out of boost energy.
