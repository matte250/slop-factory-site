Implemented a concise **Canvas Escape** game in `game.js` targeting the `<canvas id="game">` element. The script:

- Sets up responsive canvas sizing.
- Defines a player square that auto‑moves forward and can jump on click/Space.
- Generates scrolling obstacles and gaps, increasing difficulty over time.
- Handles collision detection and displays a “Game Over” screen.

The file is ready to be linked from the existing HTML page.
