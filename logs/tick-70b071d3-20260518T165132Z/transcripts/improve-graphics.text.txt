Implemented a set of visual upgrades:

* **Background** – Gradient from deep navy to black.  
* **Stars** – Pre‑generated twinkling stars with varying size, brightness and a smooth fade effect.  
* **Ship** – Added a green glow (`shadowBlur`) for a more striking look.  
* **Exhaust** – Ship now emits orange‑red particles that fade and travel leftward, creating a dynamic trail.  
* **Meteors** – Rendered as circles with radial gradients (bright core to darker edge) for a 3‑D feel.  
* **Fuel pickups** – Drawn as bright circles rather than squares.  
* **Code clean‑up** – Removed duplicated meteor‑update loop, consolidated meteor & exhaust updates, and added the exhaust‑particle array initialization.

These changes keep the original gameplay intact while delivering a richer, more polished visual experience.
