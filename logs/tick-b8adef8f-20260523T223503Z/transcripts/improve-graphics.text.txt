Implemented richer visuals:

* **Background** – pre‑generated twinkling stars, black base layer plus a vertical gradient (`#001 → #000`) for depth.  
* **Ship** – gradient hull with a thrust flame that appears when the up arrow is pressed.  
* **Beacons** – glowing circles using radial gradients for a soft pulse effect.  
* **Asteroids** – gradient “rock” fill with a dark outline, giving a more three‑dimensional look.  

All changes are in `game.js` and automatically run on the `<canvas id="game">`. The game now looks more polished while keeping the original mechanics intact.
