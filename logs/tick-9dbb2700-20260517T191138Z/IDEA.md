# Asteroid Dodge

A simple HTML canvas game where the player controls a ship at the bottom of the screen, moving left and right to dodge falling asteroids.

- **Gameplay**: Asteroids spawn at random positions and fall at increasing speeds. The ship can be moved with arrow keys or touch.
- **Lose condition**: The ship has three lives; each collision with an asteroid reduces a life. When all lives are lost, the game ends.
- **Scoring**: The score is the survival time (seconds) or number of asteroids dodged.

The core mechanics require drawing shapes, handling input, and simple collision detection, making it well‑suited for an HTML canvas implementation.
