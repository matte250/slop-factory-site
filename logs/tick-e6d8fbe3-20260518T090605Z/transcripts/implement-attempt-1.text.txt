Implemented **Asteroid Dodge** game in `game.js`:

- Targets canvas `id="game"`  
- Handles keyboard input (←/→ rotate, ↑ thrust)  
- Manages ship physics, asteroid spawning, movement, and edge‑wrap  
- Detects collisions → game over  
- Shows score based on survival time  
- Uses `requestAnimationFrame` for the game loop  

The file is ready to be included with the existing HTML page.
