# Canvas Runner

- **Genre:** Endless runner side‑scroll
- **Controls:** Space/Up arrow to jump
- **Gameplay:** A square character runs automatically across a procedurally generated platform. Gaps and obstacles appear; the player must time jumps to avoid them.
- **Lose condition:** Collision with an obstacle **or** falling into a gap ends the game.
- **Goal:** Survive as long as possible and achieve a high score based on distance traveled.

*Simple graphics and physics make it ideal for an HTML canvas implementation.*
