Added sound effects using the Web Audio API:

* **Audio setup** – created an `AudioContext`, resumed it on the first key press, and added a reusable `playTone` helper.
* **Spawn sound** – each meteor spawns a short high‑pitched swoosh.
* **Movement sound** – pressing left/right arrows plays a brief tone.
* **Collision sound** – when a meteor hits the ship, a low‑note tone plays (also serves as the game‑over cue).

All sounds are generated programmatically, so no external assets are required. The game now provides auditory feedback for key actions while preserving the existing gameplay.
