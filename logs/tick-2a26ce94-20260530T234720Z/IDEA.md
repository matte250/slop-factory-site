# Game Idea: Meteor Shower Escape

- **Genre:** Endless dodge/arcade
- **Gameplay:** The player controls a small spaceship that moves horizontally along the bottom of an HTML canvas using left/right arrow keys (or mouse). Meteors of varying sizes and speeds fall from random positions at the top of the canvas. The spawn rate and speed increase over time.
- **Goal:** Survive as long as possible; the longer you survive, the higher your score.
- **Lose Condition:** The game ends immediately when any meteor collides with the player's ship.
- **Visuals:** Simple shapes (triangular ship, circular meteors) drawn with canvas API; optional background stars.
- **Why Feasible:** All mechanics (movement, collision detection, spawning, scoring) are easily implemented with plain JavaScript and the HTML canvas element.
