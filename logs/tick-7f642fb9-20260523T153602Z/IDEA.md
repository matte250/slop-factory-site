# Game Idea: Neon Run

**Genre:** Endless runner

**Core Loop:** The player controls a neon-lit hovercraft racing forward through a procedurally‑generated, scrolling cityscape. The craft automatically moves forward; the player taps/clicks to jump over gaps and swipes left/right to dodge obstacles (broken drones, energy barriers).

**Lose Condition:** Colliding with any obstacle or falling into a gap ends the run. The game displays "Game Over" and the distance traveled.

**Key Features:**
- Simple one‑button controls suitable for mobile and desktop.
- Dynamic lighting and particle effects on HTML canvas.
- Score based on distance; leaderboards optional.

*All elements can be rendered with Canvas 2D API and plain JavaScript.*
