# Game Idea: Space Debris Dodge

- **Genre:** Endless arcade
- **Core mechanic:** Player controls a spaceship with arrow keys, navigating a constantly scrolling field of randomly generated space debris.
- **Goal:** Survive as long as possible while avoiding collisions.
- **Lose condition:** The ship has a limited shield; each collision reduces the shield, and the game ends when the shield reaches zero.
- **Scoring:** Time survived (or number of debris avoided) is tracked and displayed.
- **Canvas features:** Simple 2‑D sprite movement, basic particle effects for debris, and collision detection using bounding boxes.
