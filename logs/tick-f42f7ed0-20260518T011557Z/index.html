# Game Idea: Asteroid Escape

A minimalist HTML canvas game where the player controls a small spaceship navigating through an endless field of moving asteroids. The ship can rotate and thrust using keyboard controls. Asteroids drift from right to left at varying speeds. Colliding with any asteroid triggers a game‑over (lose condition). The goal is to survive as long as possible, with occasional fuel pickups that increase the score and provide brief speed boosts.
