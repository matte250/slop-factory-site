Implemented **Canvas Escape** game in `game.js`. The script:

- Targets the `<canvas id="game">` element.
- Handles ship movement with arrow keys.
- Spawns and animates asteroids.
- Detects collisions, reduces ship health, and ends the game after three hits.
- Renders ship, asteroids, and health status.

Add this file to your project alongside the existing HTML containing the canvas element.
