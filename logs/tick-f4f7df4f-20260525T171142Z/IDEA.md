# Canvas Catch

- **Genre:** Simple reflex game
- **Gameplay:** A player-controlled circle moves left/right at the bottom of a canvas, catching falling stars that spawn at random X positions.
- **Controls:** Arrow keys (←/→) to move.
- **Lose condition:** The game ends when a star reaches the bottom without being caught.
- **Goal:** Stay alive as long as possible; score is the number of stars caught.
