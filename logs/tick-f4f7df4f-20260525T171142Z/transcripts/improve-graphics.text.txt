Implemented enhanced graphics for the Canvas Catch game:

- **Background gradient** and moving ambient stars for depth.  
- **Radial gradient player** with smoother shading.  
- **Five‑point star shapes** with glow effect and orientation toward the player.  
- **Particle burst** when a star is caught, fading out over time.  
- **Score text** now has a subtle shadow for readability.  
- Updated game loop to animate background stars and particles each frame.  

All changes are in `game.js`, targeting the existing `<canvas id="game">`. The game now has richer visuals while retaining original gameplay.
