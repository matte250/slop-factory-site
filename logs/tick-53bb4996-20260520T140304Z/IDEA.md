# Game Idea: Neon Escape

- **Genre**: Endless runner on an HTML canvas.
- **Core loop**: Player controls a neon-lit hovercraft that automatically moves forward across a scrolling, procedurally‑generated tunnel.
- **Controls**: Left/Right arrows (or A/D) to steer; space to activate a temporary speed boost.
- **Goal**: Survive as long as possible while collecting glowing orbs for score.
- **Lose condition**: Hitting a tunnel wall or obstacle ends the game.
- **Visual style**: Minimalist neon outlines on a dark background, easy to render with simple shapes and canvas line drawing.
- **Feasibility**: Uses only canvas drawing, keyboard input, and a basic game loop – well‑within a single HTML file.
