Added sound effects:

* **Thrust** – plays on each thrust frame (`thrustAudio`).
* **Fuel pickup** – plays when collecting fuel (`fuelAudio`).
* **Explosion** – plays on collision (`explodeAudio`).

Implemented by:
1. Declaring three `Audio` objects with tiny data‑URI wav placeholders.
2. Triggering `thrustAudio` in the thrust branch of the update loop.
3. Triggering `fuelAudio` when a fuel pickup is collected.
4. Triggering `explodeAudio` when the ship collides with an asteroid.

All existing gameplay logic and the enhanced graphics remain unchanged. The game now includes basic sound feedback for key actions.
