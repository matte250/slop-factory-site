# Canvas Game Idea

**Title:** Asteroid Dodge

**Concept:** The player controls a small spaceship that continuously moves forward in a star‑filled space. Asteroids of varying sizes drift across the screen from random directions. Using the mouse or arrow keys, the player steers the ship to avoid collisions.

**Lose Condition:** The game ends when the ship collides with any asteroid. The final score is the time survived (or number of asteroids dodged).

**Core Features:**
- Simple HTML canvas rendering of ship and asteroids.  
- Incrementally increasing asteroid speed and spawn rate.  
- Score counter displayed in the corner.  
- Restart button after losing.
