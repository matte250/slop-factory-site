Implemented **Solar Swerve** game in `game.js`.  
The script targets the HTML canvas with `id="game"` and provides:

- Ship control via arrow keys or mouse movement.  
- Endless spawning of asteroids (obstacles) and occasional fuel cells.  
- Fuel gauge that depletes over time and replenishes on collection.  
- Collision detection and game‑over overlay.

Add `<script src="game.js"></script>` to the HTML page that contains the `<canvas id="game">`. The game starts automatically.
