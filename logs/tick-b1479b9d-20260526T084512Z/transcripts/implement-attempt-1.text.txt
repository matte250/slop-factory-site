Implemented **game.js** with a concise, functional endless‑scroll mining drone game:

* Targets the existing `<canvas id="game">`.
* Handles player movement (arrow keys), random asteroid and gem spawning, collision detection, hull integrity, score tracking, and game‑over overlay.
* Runs a self‑contained animation loop using `requestAnimationFrame`.

Add this script to the HTML page that contains the canvas to activate the game.
