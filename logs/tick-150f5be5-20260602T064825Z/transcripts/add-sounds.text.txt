Implemented sound effects:

- Added an `AudioContext` with a resume handler for first user interaction.
- Created `playTone(freq, duration)` to generate simple synth tones.
- Played a thrust sound while the ship accelerates (capped at ~6 Hz).
- Played a collision sound when the ship hits an asteroid. 

All changes are in `game.js`; the game now has audible feedback while preserving the existing graphics and gameplay.
