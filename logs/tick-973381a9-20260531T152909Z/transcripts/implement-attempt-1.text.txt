Implemented **Orbit Defender** as a concise `game.js` that targets the existing `<canvas id="game">`. The script:

- Sets up canvas sizing and resizing.
- Manages ship orbit, rotation (←/→), and firing (Space) with simple input handling.
- Spawns, moves, and checks collisions for asteroids.
- Handles bullet creation, movement, and collision detection.
- Renders planet, ship, bullets, asteroids, and score; displays a game‑over overlay.

Attach this file to the HTML page containing the canvas to run the game.
