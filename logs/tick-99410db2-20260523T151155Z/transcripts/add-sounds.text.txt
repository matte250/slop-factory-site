Added Web Audio‑API based sound effects:

* **Background hum** – a low‑frequency sine oscillator starts on the first key press (`startBackground()`).
* **Asteroid spawn beep** – a short square‑wave beep (`playBeep(200, 0.05)`) each time a new asteroid is created.
* **Collision crash beep** – a lower‑frequency, longer beep (`playBeep(100, 0.4)`) when the ship collides with an asteroid.

Audio context is created once, and the background oscillator runs continuously while the game is active. No external audio files are required.
