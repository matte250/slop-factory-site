# Game Idea: Cosmic Dodger

A minimalist HTML Canvas endless‑runner where the player pilots a tiny spaceship moving forward through a field of randomly generated asteroids. The ship can tilt left/right and boost forward. Each collision reduces a shield meter; the shield starts at 3 points. When the shield reaches zero, the game ends (lose condition). The goal is to survive as long as possible and achieve a high score based on distance traveled.

**Key elements**
- Simple 2‑D graphics drawn with Canvas API.
- Arrow keys (or WASD) for movement.
- Randomly spaced asteroids with varying sizes.
- Visual shield indicator.
- Score displayed as distance.
