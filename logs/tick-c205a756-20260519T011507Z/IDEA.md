# Game Idea: Neon Escape

Control a neon triangle that continuously moves forward in an endless scrolling arena of rotating obstacles. The player can rotate the triangle left or right to pass through gaps. Collect glowing orbs for points. Lose if the triangle collides with an obstacle or runs out of time (timer counts down when no orb is collected for 10 seconds).

The game can be implemented using a single HTML canvas, with simple polygon rendering, collision detection, and a UI overlay for score and timer.
