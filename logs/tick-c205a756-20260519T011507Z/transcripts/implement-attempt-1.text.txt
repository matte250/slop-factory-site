Implemented **`game.js`** with a minimal “Neon Escape” game:

* Targets canvas with id `game`
* Renders a neon triangle that can rotate left/right (arrow keys)
* Generates rotating rectangular obstacles and glowing orbs
* Handles collision detection, scoring, and a timer that decrements when no orb is collected for 10 seconds
* Displays current score and time

The file is ready to be included in the existing HTML page.
