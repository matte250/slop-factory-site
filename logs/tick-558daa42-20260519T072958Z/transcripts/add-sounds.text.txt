Implemented game sounds:

- Created an **AudioContext** and a reusable `beep(freq, duration)` helper.
- Resumes the audio context on the first key press for user interaction compliance.
- Plays a short low‑tone beep when a new asteroid spawns.
- Plays a crash beep when the ship collides with an asteroid.

All audio logic lives in `game.js`, still targeting the existing `<canvas id="game">`. The game now has basic sound effects while preserving its gameplay and graphics.
