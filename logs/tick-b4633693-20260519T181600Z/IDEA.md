# Game Idea: Cosmic Drift

A minimalist HTML canvas game where the player pilots a tiny spaceship through an endless field of drifting asteroids.
- **Controls**: Click‑drag or arrow keys to thrust in any direction.
- **Goal**: Survive as long as possible, collecting occasional power‑ups for speed or shield.
- **Lose condition**: The game ends if the ship collides with an asteroid or sails off the canvas boundaries.
- **Win condition**: There is no fixed win; the challenge is achieving the highest survival time/score.
