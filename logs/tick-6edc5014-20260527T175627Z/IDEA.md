# Gravity Flip Game Idea

- **Core mechanic**: The player controls a simple shape moving continuously to the right on an HTML canvas.
- **Gravity flip**: Pressing space (or tapping) flips gravity, causing the shape to fall upward or downward.
- **Obstacles**: Platforms, gaps, and spikes appear that must be avoided by timing gravity flips.
- **Lose condition**: The player loses if they collide with a spike or fall off the top/bottom edge of the canvas.
- **Goal**: Survive as long as possible while the game speed gradually increases.
- **Visuals**: Minimalist graphics using canvas primitives (rectangles, circles).
