Implemented a richer visual experience:

* **Background** – fills canvas with black each frame.
* **Starfield** – generates and renders twinkling stars that resize with the canvas.
* **Ship** – uses a cyan‑to‑dark gradient for a more polished look.
* **Asteroids** – each asteroid now has its own radial gradient, random rotation, and rotates while falling.
* **Render flow** – draws stars before game objects and clears with a colored background.

All changes are contained in `game.js` and work with the existing `<canvas id="game">`.
