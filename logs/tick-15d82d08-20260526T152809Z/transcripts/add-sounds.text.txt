Added sound effects using the Web Audio API:

- **Audio setup**: Created an `AudioContext` and helper functions `playTone` (for score increments) and `playExplosion` (for collisions).  
- **Score sound**: Plays a short high‑pitched tone whenever an asteroid leaves the screen and the score increments.  
- **Collision sound**: Triggers a low‑frequency burst when the ship collides with an asteroid, then ends the game.

All changes are within **game.js**, preserving existing gameplay while adding auditory feedback.
