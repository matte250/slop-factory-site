Implemented a concise **Space Miner** game in `game.js` that targets the `<canvas id="game">` element. The script handles:

- Ship movement with thrust, rotation, fuel consumption, and hull health.
- Drifting asteroids and mining via laser shots (Space key).
- Collision detection for damage and asteroid mining.
- Simple UI showing fuel, hull, and a “Game Over” overlay.

Add this script to your HTML page to run the game.
