Implemented audio feedback:

* Created an `AudioContext` and a `playTone(freq, dur)` helper.
* Added a click‑handler that resumes the audio context (required for first user interaction), plays a short 440 Hz tone, then changes lanes.
* Played a lower 200 Hz tone when a collision ends the game.

All changes are in **`game.js`** and integrate seamlessly with the existing canvas‑based runner. The game now provides immediate sound cues for lane changes and game‑over events, enhancing the player experience.
