# Game Idea: Light Runner

- **Genre:** Minimalist arcade
- **Core mechanic:** Control a glowing orb moving through a dark maze. The orb's light reveals the path and hidden hazards.
- **Goal:** Collect as many scattered crystals as possible.
- **Lose condition:** Touching a shadow enemy or running out of light (timer) ends the game.

The game can be implemented with HTML Canvas using simple shapes and collision detection.
