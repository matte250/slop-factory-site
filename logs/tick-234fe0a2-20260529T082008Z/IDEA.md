# Game Idea: Cosmic Dodger

- **Genre:** Arcade / Endless runner.
- **Core mechanic:** Player controls a ship at the bottom of the canvas, moving left/right to dodge falling asteroids.
- **Goal:** Survive as long as possible, earning points for each asteroid avoided.
- **Lose condition:** The game ends when an asteroid collides with the ship.
- **Features:** Simple HTML canvas graphics, particle explosion on collision, high‑score tracking.
