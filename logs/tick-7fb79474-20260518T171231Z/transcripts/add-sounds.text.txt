Added sound effects:

* Loaded three audio assets (`collect.wav`, `crash.wav`, `bg.mp3`) and set the background music to loop.
* Started background music after the first key press (user interaction) to satisfy browser autoplay rules.
* Played the **collect** sound whenever an orb is collected.
* Played the **crash** sound when the game ends (collision or fuel depletion).

All audio handling is encapsulated in the `sounds` object, and playback errors are silently ignored to avoid breaking the game if a file is missing. Include the audio files in the same directory as `game.js` or adjust the paths accordingly.
