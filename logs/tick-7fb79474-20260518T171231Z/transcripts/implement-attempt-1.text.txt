Implemented **Nebula Escape** game in `game.js`.

Key points:
- Targets `<canvas id="game">`.
- Handles ship movement via arrow keys.
- Spawns scrolling obstacles and collectible energy orbs.
- Tracks score and fuel, ends game on collision or fuel depletion.
- Renders simple UI with score and fuel.

Add the script to the HTML page (`<script src="game.js"></script>`) to run the game.
