# Game Idea

**Title:** Pixel Dash
**Genre:** Endless runner
**Core Loop:** A small square (the player) runs automatically across a scrolling platform. Press any key or tap to jump over gaps and dodge randomly generated obstacles. The scrolling speed increases over time.
**Lose Condition:** The game ends when the player collides with an obstacle or falls off the platform.
**Canvas Feasibility:** Uses simple shapes, basic physics, and collision detection, all easily implemented with the HTML5 `<canvas>` API.
