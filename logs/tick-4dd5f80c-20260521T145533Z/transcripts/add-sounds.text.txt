Added **audio effects** to the Orbit Escape game:

* **Web Audio API** initialization with a `playTone` helper and automatic resume on first user interaction.
* **Thrust** – a short square‑wave tone each frame the ship fires.
* **Orb collection** – a bright triangle tone (800 Hz) when an orb is collected.
* **Collision** – a low‑pitch sawtooth tone (200 Hz) when the ship hits an asteroid.
* Updated the key handling to trigger these sounds.

The game now features responsive sound feedback while preserving the existing mechanics and enhanced graphics.
