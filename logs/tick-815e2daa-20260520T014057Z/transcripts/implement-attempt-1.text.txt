Implemented **Asteroid Escape** game in `game.js`.

- Targets canvas element with `id="game"`.
- Features:
  - Ship control (↑/↓ or W/S) with boundary limits.
  - Endless scrolling asteroids that end the game on collision.
  - Randomly spawning fuel cells to replenish fuel and increase score.
  - Fuel consumption over time; game ends when fuel depletes or collision occurs.
  - UI displaying fuel level and score, plus a game‑over overlay.
