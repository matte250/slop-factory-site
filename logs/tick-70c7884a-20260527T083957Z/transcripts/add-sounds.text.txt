Implemented sound effects using the Web Audio API:

- Initialized an `AudioContext` that resumes on the first user interaction (click or touch).
- Added helper functions `playTone`, `playCollect`, and `playCrash`.
- Triggered `playCollect()` when the ship collects a particle.
- Triggered `playCrash()` when the ship collides with an asteroid.

All audio logic is integrated into `game.js`, enhancing the gameplay experience with auditory feedback.
