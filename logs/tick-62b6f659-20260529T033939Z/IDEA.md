# Game Idea: Canvas Survival

- **Genre:** Simple 2D endless runner on HTML canvas.
- **Core mechanics:** Player controls a colored square that automatically runs left‑to‑right. Tap/space to jump over incoming rectangular obstacles.
- **Goal:** Travel as far as possible while collecting floating coins for score.
- **Lose condition:** Colliding with an obstacle or falling off the ground ends the game.
- **Visuals:** Minimalist shapes and background, all drawn with canvas API.
- **Controls:** Keyboard (space) or mouse click/tap.
