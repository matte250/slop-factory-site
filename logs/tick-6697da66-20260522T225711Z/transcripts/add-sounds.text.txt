Added sound effects using the Web Audio API:

- **Audio context** initialized and resumed on the first key press.
- **playTone(freq, duration)** helper creates short sine‑wave tones.
- **Turn sounds** play when the player rotates left/right.
- **Collision sound** (low buzz) triggers on wall contact.
- **Collect sound** (high ping) plays when an orb is collected.

All audio logic is integrated directly into **game.js**, so the game now provides auditory feedback while preserving existing functionality.
