Implemented a minimal side‑scroll runner game in **`game.js`** that targets the existing canvas (`id="game"`). The script:

- Sets up canvas context and dimensions  
- Defines a player object with simple jump physics  
- Generates random obstacles that scroll leftward  
- Checks for collisions, ending the game on impact  
- Starts the loop on first canvas click and handles subsequent jumps via click events  

Add `<script src="game.js"></script>` to the HTML to run the game.
