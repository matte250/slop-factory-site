Implemented audio feedback and richer visuals:

- Created an `AudioContext` and a reusable `playBeep(freq, duration)` helper.
- Resumes the audio context on the first key press (required for browsers that suspend audio until user interaction).
- Plays a low‑frequency beep when the ship collides with an asteroid (game‑over sound).
- Added a vertical nebula gradient (`bgGrad`) for the space background.
- Cleaned up drawing order: nebula gradient → stars → ship → asteroids → UI.
- Updated score text color for better contrast.  

The game now features atmospheric background graphics and a simple crash sound while preserving the original gameplay.
