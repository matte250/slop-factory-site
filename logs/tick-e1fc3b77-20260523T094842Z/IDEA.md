# Game Idea: Asteroid Dodge

**Concept**: A single-screen HTML5 canvas game where the player pilots a ship to dodge incoming asteroids.

- **Controls**: Arrow keys or WASD to move the ship.
- **Gameplay**: Asteroids spawn from the edges and move toward the center with increasing speed.
- **Lose Condition**: Collision with any asteroid ends the game.
- **Scoring**: Survival time (seconds) and optional fuel pickups increase the score.

The game is simple to implement with canvas drawing, basic physics, and a game loop.
