Added audio support:

- Created an `AudioContext` with simple tone‑based sound helpers.
- Background melody starts on the first key press and resumes if the context is suspended.
- `playCollect()` triggers when a fuel cell is collected.
- `playCrash()` triggers on asteroid collision.
- Integrated sound calls into collision logic.

All changes are in **game.js**, enhancing the game with responsive sound effects while keeping the existing gameplay intact.
