# Game Idea: **Pixel Runner**

A side‑scrolling endless runner rendered on an HTML canvas. The player controls a pixel‑art character that automatically moves forward and can jump to avoid randomly generated obstacles (spikes, gaps, moving blocks). The game ends (lose condition) when the character collides with an obstacle or falls off the bottom of the screen. Playtime is tracked for high‑score competition.
