Implemented **Pixel Runner** in `game.js`. The script targets the existing canvas with `id="game"` and provides:

- Canvas setup (800 × 200 px)
- Player character with gravity, jumping (Space/ArrowUp)
- Randomly spawning spike and gap obstacles
- Collision detection, scoring, and a game‑over overlay
- Continuous animation loop using `requestAnimationFrame`

Add this script to the HTML page containing the `<canvas id="game"></canvas>` to run the game.
