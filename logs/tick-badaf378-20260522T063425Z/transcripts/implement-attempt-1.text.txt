Implemented **game.js** with a concise top‑down endless runner:

- Targets the canvas element with `id="game"`.
- Handles player movement via left/right arrow keys.
- Spawns random triangular obstacles that move downward.
- Detects collisions, shows a “Game Over” alert, and resets the game.
- Tracks and displays the distance‑based score.
- Uses `requestAnimationFrame` for smooth animation.

The file is ready to be referenced by the existing HTML.
