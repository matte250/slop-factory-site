Added sound effects using the Web Audio API:

* Created an `AudioContext` and a reusable `playTone(freq, duration)` helper.
* Added a tone when the player moves (different pitch for left/right).
* Played a short tone each time a new obstacle spawns.
* Resumes the audio context on the first user interaction.

All changes are in **game.js**, preserving existing gameplay while enhancing the audio experience.
