Added audio to the game:

- Created an `AudioContext` with helper functions that generate simple tones for thrust, fuel collection, and collision.
- Resumes the audio context on the first user interaction to satisfy browser autoplay policies.
- Plays a thrust sound when the player presses the forward/backward keys.
- Plays a fuel‑pickup sound when a fuel cell is collected.
- Plays a collision sound when the game ends due to a crash.

All changes are in **game.js**, targeting the existing `<canvas id="game">`. The game now includes responsive sound effects for core actions.
