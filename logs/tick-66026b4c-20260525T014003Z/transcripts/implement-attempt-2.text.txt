Implemented **game.js** with a concise Asteroid Dodger game that:

- Targets the `<canvas id="game">` element.
- Handles canvas resizing.
- Provides player movement (left/right) with keyboard controls.
- Spawns falling asteroids, updates their positions, and draws them.
- Detects collisions and displays a “Game Over” overlay.

The file is now ready to be included in the HTML page.
