Implemented a concise endless‑runner game in **`game.js`** that targets the canvas element with `id="game"`.

Key features:
- Rocket physics with gravity and thrust (click/tap).
- Randomly generated top/bottom obstacles scrolling left.
- Collision detection and lose condition.
- Simple starry background, scoring, and “Game Over” overlay.
- Automatic reset on click after game over.

The script runs immediately, initializing the game loop and handling input.
