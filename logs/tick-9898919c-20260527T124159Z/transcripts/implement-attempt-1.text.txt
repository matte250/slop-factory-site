Implemented **Neon Light Runner** in `game.js`.

- Targets `<canvas id="game"></canvas>` and sets up canvas dimensions.
- Handles ship physics, input (click/tap to ascend), obstacle/orb spawning, collision detection, energy management, and scoring.
- Uses `requestAnimationFrame` for the main loop, drawing the game scene each frame.
- Displays score and an energy bar; alerts the user on game over and resets the game.

The game is now ready to be linked from the existing HTML page.
