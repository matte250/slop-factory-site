Implemented **Pixel Escape** game in `game.js`.

- Targets the existing `<canvas id="game">`.
- Handles player movement (arrow keys), block spawning, collision detection, timer, and win condition (reach right edge).
- Resizes canvas to match displayed size and updates on window resize.
- Uses simple colors for player, blocks, and exit.

The script is self‑contained and ready to be included in the HTML page.
