The **Neon Runner** game has been created as `game.js` in the workspace. It targets the canvas element with `id="game"` and implements:

- Canvas resizing to fill its container.  
- Player physics (gravity, jump) with input via spacebar or click/tap.  
- Procedurally generated scrolling world segments with random gaps and spikes.  
- Collision detection for spikes and gaps, triggering a game‑over state.  
- Scoring system with persistent high score via `localStorage`.  
- Rendering of background, ground, spikes, player, and UI overlay.

You can now load the HTML page containing `<canvas id="game"></canvas>` and the game will run automatically.
