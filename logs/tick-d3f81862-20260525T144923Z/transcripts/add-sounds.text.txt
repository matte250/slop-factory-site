Implemented audio:

- Added a lightweight Web Audio API helper (`playTone`) and created an `AudioContext`.
- Added thrust sound (200 Hz, 80 ms) triggered each time the ship thrusts.
- Added explosion sound (100 Hz, 500 ms) played on collision before the game‑over alert.
- Ensured the audio context resumes on the first key press for browsers that start it in a suspended state.  

All other game mechanics and graphics remain unchanged.
