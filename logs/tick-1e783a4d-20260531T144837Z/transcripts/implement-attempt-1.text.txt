Implemented **game.js** with a concise asteroid‑dodge game:

- Targets canvas element `id="game"`.
- Handles keyboard and mouse movement for the ship.
- Spawns asteroids and collectible stars, increases difficulty over time.
- Detects collisions, tracks score, and shows a “Game Over” overlay.
- Uses `requestAnimationFrame` for smooth animation.

The file is ready to be linked from the existing HTML.
