# Game Idea: Asteroid Dodge

- **Genre**: Endless arcade / arcade shooter.
- **Controls**: Arrow keys or mouse to move a small ship (triangle) across the canvas.
- **Gameplay**: Asteroids of varying sizes spawn from the top and fall downward, accelerating over time. The ship can collect floating stars for points.
- **Lose Condition**: The game ends immediately when any asteroid collides with the ship.

A simple implementation can be done with vanilla JavaScript drawing on an HTML `<canvas>` element, using requestAnimationFrame for the game loop.

    osc.type = 'square';
    osc.connect(gain);
    gain.connect(audioCtx.destination);
