```
# Asteroid Dodge

**Concept**  
A minimalist HTML canvas game where the player controls a ship that can rotate and thrust forward. Asteroids spawn from the edges and travel toward the center.

**Gameplay**  
- Arrow keys rotate the ship; space bar thrusts forward.  
- Click to fire lasers that destroy asteroids.  
- Score increases for each destroyed asteroid.

**Lose Condition**  
The game ends when an asteroid collides with the ship or the ship drifts off the canvas bounds.

**Why it works in Canvas**  
Simple shapes (triangles, circles) and basic physics can be drawn and updated each frame with the canvas 2D API.
```
