Implemented enhanced graphics for the **Color Chase** game:

- Added high‑DPI canvas handling with automatic resizing.
- Background now uses a vertical gradient.
- Player circle rendered with a radial gradient and drop shadow.
- Falling squares are drawn as rounded rectangles with shadows.

All changes are in **game.js** and work with the existing `<canvas id="game">`. Enjoy the upgraded visuals!
