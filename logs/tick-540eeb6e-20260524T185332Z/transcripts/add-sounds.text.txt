Added sound effects using the Web Audio API:

- **Audio setup**: created an `AudioContext` with simple `playTone` helper.
- **Spawn sound**: short high‑pitched tone played each time a circle spawns.
- **Hit sound**: lower‑pitched tone played when the player collides with a circle (game over).

Integrated these calls into the existing spawn and collision logic, preserving all previous graphics improvements. The game now has visual and auditory feedback.
