# Random HTML Canvas Game Idea

**Title:** Neon Void Escape

**Concept:**
- The player pilots a small ship that constantly moves forward in a 2D space.
- The canvas scrolls vertically, and neon-colored geometric obstacles appear from the top.
- The ship can rotate left/right and thrust forward to dodge obstacles.
- Colliding with any obstacle triggers the **lose condition**.

**Core Features:**
- Simple physics: rotation and thrust.
- Procedurally generated obstacles with varying speed and size.
- Score based on distance traveled.
- Minimalist neon aesthetic for easy rendering on canvas.

**Possible Extensions:**
- Power‑ups (shield, speed boost).
- High‑score leaderboard.

**Lose Condition:** Collision with an obstacle ends the game.
