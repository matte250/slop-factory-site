Implemented **Neon Void Escape** game in `game.js`. It targets the canvas with `id="game"` and includes:

- Ship movement with rotation and thrust controls (arrow keys/WASD)
- Procedurally generated neon obstacles scrolling down
- Collision detection and game‑over handling
- Score tracking based on obstacles dodged
- Minimal neon visual style

Add `<canvas id="game"></canvas>` to your HTML and include this script to run the game.
