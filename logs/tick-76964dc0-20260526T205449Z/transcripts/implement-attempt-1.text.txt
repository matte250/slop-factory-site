Implemented **Neon Runner** as `game.js`:

- Targets the existing `<canvas id="game">`.
- Resizes canvas to viewport, handles keyboard input (arrow keys/WASD).
- Player is a neon‑cyan square that moves within the canvas.
- Generates scrolling vertical obstacles with a gap; collision ends the game.
- Shows “Game Over” message on failure.

The file is ready to be included in the HTML page.
