Added simple sound effects using the Web Audio API:

* **Audio context** created and helper functions (`playTone`, `playShoot`, `playExplosion`, `playGameOver`) added.
* Shooting triggers a short 440 Hz tone.
* Alien destruction plays a lower‑frequency explosion tone.
* Game over triggers a final descending tone.
* Integrated these calls into the existing input, collision, and game‑over logic.

All changes are in `game.js`, preserving the existing canvas interaction while enhancing the experience with audio feedback.
