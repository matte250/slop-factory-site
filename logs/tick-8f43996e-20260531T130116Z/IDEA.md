# Game Idea: Canvas Escape

**Concept**: A top‑down view where the player controls a tiny square navigating a maze of moving barriers inside an HTML canvas. The goal is to collect glowing tokens while avoiding colliding with any barrier.

**Lose Condition**: The game ends when the player collides with a barrier or fails to collect a token within a time limit.

**Core Mechanics**:
- Arrow keys or WASD to move the square.
- Barriers move in predictable patterns.
- Tokens appear randomly and grant points.
- Simple graphics and physics suitable for plain Canvas API.

**Why It Works**: Requires only basic drawing, collision detection, and input handling—perfect for an HTML canvas prototype.
