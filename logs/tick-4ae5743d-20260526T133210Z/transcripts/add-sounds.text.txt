Implemented audio feedback:

- Added **Web Audio API** setup with `audioCtx`.
- Created helper `playTone` for simple beep synthesis.
- Added `scoreSound` (high‑pitched beep) triggered when an asteroid exits the screen.
- Added `collisionSound` (low‑pitched beep) triggered on ship‑asteroid collision.

All changes are in **game.js**, preserving existing gameplay while providing sound effects.
