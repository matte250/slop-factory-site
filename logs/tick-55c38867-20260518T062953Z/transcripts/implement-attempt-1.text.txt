Implemented **Stellar Drift** in `game.js`:

- Targets the canvas with `id="game"`  
- Handles ship movement, rotation, and thrust  
- Spawns asteroids and glowing orbs from canvas edges  
- Detects collisions → game over, and orb collection → score  
- Renders ship, obstacles, orbs, and UI (score & game‑over overlay)  
- Runs a request‑animation‑frame loop for smooth updates  

The game is ready to run alongside the existing HTML file.
