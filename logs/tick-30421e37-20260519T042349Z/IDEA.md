# Game Idea: Canvas Asteroid Dodge

- **Genre**: Endless arcade / survival
- **Core Loop**: The player controls a ship with arrow keys (or mouse) that moves horizontally across the bottom of the canvas. Asteroids of varying sizes fall from the top at increasing speed.
- **Goal**: Survive as long as possible; each avoided asteroid adds to the score.
- **Lose Condition**: Collision between the ship and any asteroid ends the game.
- **Visuals**: Simple vector shapes (triangles for the ship, circles for asteroids) rendered on an HTML5 canvas.
- **Extensions**: Power‑ups, different ship weapons, high‑score leaderboard.
