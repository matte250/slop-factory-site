# Game Idea: **Astro Dash**

- **Genre:** Endless arcade/avoidance.
- **Core Loop:** The player pilots a small ship on an HTML canvas, constantly moving forward. Asteroids and debris scroll toward the ship.
- **Controls:** Arrow keys (or WASD) to thrust up/down/left/right.
- **Goal:** Survive as long as possible, racking up distance.
- **Lose Condition:** The ship crashes into any obstacle or exits the canvas bounds.

*Simple graphics and physics make it easy to implement with Canvas 2D.*
