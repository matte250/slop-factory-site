# Game Idea: Asteroid Dodge
- **Genre**: Arcade / Action  
- **Play area**: HTML5 canvas where asteroids fall from the top.  
- **Player**: Small ship that moves horizontally along the bottom and fires lasers.  
- **Goal**: Destroy as many asteroids as possible to earn points.  
- **Lose condition**: The player loses when an asteroid collides with the ship or reaches the bottom of the canvas.  
- **Features**: Gradually increasing fall speed, power‑ups for rapid fire, and a high‑score leaderboard.  

A simple, self‑contained canvas game that can be built with vanilla JavaScript.
