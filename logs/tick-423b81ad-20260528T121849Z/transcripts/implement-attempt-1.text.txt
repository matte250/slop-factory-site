Implemented a concise **Asteroid Dodge** game in `game.js` that targets the existing `<canvas id="game">`. The script:

- Sets up canvas sizing and context.
- Handles ship movement with arrow keys and vertical wrap.
- Spawns and updates random asteroids.
- Performs simple circle‑based collision detection.
- Shows a “Game Over” message on collision.
- Tracks and displays a score based on survival time.

Include this script in the HTML page that contains the canvas to run the game.
