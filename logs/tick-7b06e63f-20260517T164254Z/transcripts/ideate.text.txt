# Game Idea: Canvas Runner

A simple endless runner on an HTML `<canvas>`. The player controls a character that automatically moves forward and must jump over or slide under randomly generated obstacles.

- **Controls:** Tap/space to jump, down‑arrow to slide.  
- **Goal:** Survive as long as possible while the speed gradually increases.  
- **Lose Condition:** The game ends when the character collides with an obstacle or falls into a gap.  
- **Visuals:** Pixel‑art style with a scrolling background.

The idea fits within a single HTML page using plain JavaScript and the Canvas 2D API.
