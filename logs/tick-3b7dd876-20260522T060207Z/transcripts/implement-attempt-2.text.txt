The **`game.js`** file has been created and implements the “Nebula Escape” endless‑runner based on the description in **IDEA.md**.

- Targets the `<canvas id="game">` element.
- Handles ship movement (up/down), fuel consumption, asteroid collisions, fuel pickups, and a simple game‑over screen.
- Uses `requestAnimationFrame` for the main loop and draws all elements on the canvas.
