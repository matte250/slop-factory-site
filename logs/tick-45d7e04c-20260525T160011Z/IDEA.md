# Random Canvas Game Idea

**Title:** Falling Blocks Dodge

- The player controls a small square that moves left/right at the bottom of the canvas.
- Colored blocks fall from the top with varying speeds.
- The player must dodge the blocks; touching a block ends the game.
- A simple score increments for each second survived.
- Lose condition: collision between the player square and any falling block.

The game can be built with pure HTML5 canvas, using basic shapes and keyboard input.
