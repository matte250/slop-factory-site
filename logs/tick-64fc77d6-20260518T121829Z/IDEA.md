# Game Idea: Cosmic Dodge

**Overview**: A simple HTML canvas game where the player pilots a tiny spacecraft navigating through an endless field of moving asteroids.

**Controls**: Arrow keys (or WASD) to move up/down/left/right.

**Goal**: Survive as long as possible while dodging asteroids. Collect occasional power‑ups that grant temporary shields or speed boosts.

**Lose Condition**: The game ends immediately when the spacecraft collides with an asteroid without an active shield.
