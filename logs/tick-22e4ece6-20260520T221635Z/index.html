# Game Idea: Space Escape

- Control a spaceship navigating an endless field of moving asteroids.
- Use arrow keys (or WASD) to steer; spacebar for a temporary boost.
- Collect fuel cells for points and to extend play time.
- **Lose condition:** Collide with an asteroid **or** run out of fuel.
- Simple graphics with circles and lines drawn on an HTML canvas.
