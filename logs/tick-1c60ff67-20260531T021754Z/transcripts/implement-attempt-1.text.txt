Implemented **Asteroid Escape** game in `game.js`.  

- Targets the `<canvas id="game">` element.  
- Handles ship rotation, thrust, friction, and boundary loss.  
- Spawns random asteroids from canvas edges, moves them, and removes off‑screen ones.  
- Detects collisions to trigger a game‑over overlay.  
- Runs an animation loop using `requestAnimationFrame`.
