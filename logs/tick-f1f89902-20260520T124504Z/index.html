# Canvas Game Idea

**Title:** Space Debris Dodge

**Concept:** The player controls a small spaceship navigating an endless field of moving space debris on an HTML canvas. The ship can thrust in any direction using arrow keys or WASD, and must avoid colliding with debris that scrolls in from the top and sides.

**Lose Condition:** The game ends when the spaceship collides with any piece of debris. The final score (distance traveled) is displayed.
