Implemented **`game.js`**:

- Targets the `<canvas id="game">` element.
- Handles responsive canvas resizing.
- Manages game state (score, shields, falling objects, player movement via mouse or arrow keys).
- Renders a starfield background, player ship, and various debris/asteroids.
- Includes collision detection, scoring, shield loss, and a game‑over overlay.
- Provides simple UI displaying score and shields.
