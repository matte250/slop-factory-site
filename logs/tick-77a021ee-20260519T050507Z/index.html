# Game Idea: Cosmic Dodger

- 2D top‑down HTML canvas where a spaceship drifts forward automatically.
- Player can rotate left/right and boost to avoid obstacles.

- Score increases with survival time.
- Simple graphics and controls make it easy to implement.
