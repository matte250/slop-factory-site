Implemented enhanced graphics for the Asteroid Dodge game:

- Added a dynamic starfield background with twinkling stars.
- Applied gradient shading to the ship and radial gradients to asteroids.
- Implemented glowing laser effects using canvas shadows.

- Integrated star twinkling updates into the game loop.

All changes are in `game.js`, ready for a more visually appealing experience.
