Implemented audio for **Neon Grid Escape**:

- Added an `AudioContext` that resumes after the first key press (satisfies browser autoplay policies).  
- Created a reusable `playTone(freq, duration)` helper for short sound effects.  
- Started a low‑frequency background hum that runs continuously while the game is alive.  
- Played a collision tone (200 Hz, 0.2 s) when the ship hits an obstacle.  
- Stopped the background hum on game‑over to clean up the audio.  

All changes are in `game.js`; the game now has ambient music and collision feedback while preserving the existing gameplay and graphics.
