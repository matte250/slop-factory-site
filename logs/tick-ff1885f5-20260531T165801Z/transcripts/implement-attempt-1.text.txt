Implemented **game.js**:

- Targets the canvas with `id="game"`.
- Resizes canvas to fill the window.
- Adds a controllable ship (arrow keys or mouse).
- Spawns random asteroids scrolling left‑to‑right.
- Detects collisions, ends the game, and displays a score.

The file can be included in the existing HTML to run the endless side‑scroll runner described in `IDEA.md`.
