# Game Idea: Asteroid Escape

- **Genre:** Endless side‑scroll runner.
- **Gameplay:** Player controls a ship moving up/down with arrow keys (or mouse) while the canvas scrolls right‑to‑left. Asteroids of random size and speed appear from the right.
- **Goal:** Survive as long as possible, scoring by distance.
- **Lose Condition:** Collision with any asteroid or leaving the vertical bounds of the canvas ends the game.
