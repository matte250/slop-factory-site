# Game Idea: Space Dodger

- **Genre**: Endless runner / dodging
- **Canvas**: HTML5 canvas with simple 2D graphics.
- **Core loop**: The ship continuously moves upward; player steers left/right to avoid incoming asteroids.
- **Controls**: Arrow keys or WASD.
- **Lose condition**: Collision with any asteroid or moving off the visible canvas.
- **Goal**: Survive as long as possible, accumulating points by passing asteroids.
