Implemented richer graphics and added sound effects:

- **Background:** Gradient sky with a pre‑generated starfield.
- **Meteors:** Gradient shading for a 3‑D look.
- **Explosions:** Particle system with orange particles.
- **Audio:** Simple Web Audio API tones for laser fire, meteor explosions, and game‑over.
- **Game Over:** Plays a low‑tone sound before displaying the overlay.

All changes are in `game.js`; the canvas with `id="game"` now renders a more polished visual experience with auditory feedback.
