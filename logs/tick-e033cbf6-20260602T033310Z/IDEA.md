# Canvas Game Idea

**Title:** Asteroid Dodge

**Concept:** Control a small spaceship on an HTML canvas, dodging continuously spawning asteroids that move from right to left. Use arrow keys or WASD to move. The background scrolls to simulate forward motion.

**Lose Condition:** The game ends when the spaceship collides with any asteroid or drifts off the visible canvas area.

**Goal:** Survive as long as possible; score increases over time.
