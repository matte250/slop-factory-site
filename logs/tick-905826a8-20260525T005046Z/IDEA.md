# Game Idea: Asteroid Dodge

- **Genre:** Arcade / Endless runner
- **Canvas Size:** 800×600
- **Player:** Small ship that moves left/right with Arrow keys (or A/D) and can boost with Space.
- **Mechanic:** Asteroids spawn from the top at increasing speed. The ship must dodge them.
- **Scoring:** Survival time or distance traveled.
- **Lose Condition:** Collision with an asteroid ends the game (or after 3 hits if using lives).

This concept is simple to implement using HTML5 Canvas, `requestAnimationFrame`, and basic collision detection.
