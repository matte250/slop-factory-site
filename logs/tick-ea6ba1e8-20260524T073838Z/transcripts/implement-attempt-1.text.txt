Implemented a minimal endless‑runner game in **`game.js`** that targets the canvas with `id="game"`.

- Sets up player movement (arrow keys) and bounds checking.
- Randomly spawns obstacles (red squares) and collectible stars (yellow circles).
- Handles collision detection, scoring, and game‑over overlay.
- Runs an animation loop using `requestAnimationFrame`.

The script is ready to be included alongside the existing HTML canvas.
