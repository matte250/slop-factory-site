Implemented **game.js** with a concise Asteroid Dodge game that:

- Targets the canvas element `id="game"`.
- Handles ship movement (left/right) via arrow keys or **A/D**.
- Spawns falling asteroids that increase speed over time.
- Detects collisions, ends the game on impact, and displays a “Game Over” overlay.

The file is ready for inclusion in the existing HTML page.
