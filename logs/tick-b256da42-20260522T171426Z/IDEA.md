# Game Idea

**Title:** Nebula Runner

**Concept:** The player pilots a small ship across an endless starfield on an HTML canvas, using arrow keys to dodge randomly generated asteroids and collect occasional power‑ups. The background scrolls continuously to simulate forward motion, creating a simple yet engaging endless‑runner experience.

**Lose Condition:** The game ends if the ship collides with an asteroid or drifts off the canvas bounds.
