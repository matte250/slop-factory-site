Added in‑game audio using the Web Audio API:

- **Audio context** and simple tone‑generator helpers (`playTone`, `playShoot`, `playExplosion`, `playGameOver`).
- Shooting triggers `playShoot()`.
- Asteroid destruction triggers `playExplosion()`.
- Collision with the ship or reaching the bottom triggers `playGameOver()`.
- Resumes the audio context on first key press to satisfy browsers that require user interaction.

All other game logic remains unchanged, preserving the enhanced graphics from earlier. Enjoy the new sounds!
