# Game Idea: Space Miner

- Top‑down HTML canvas where the player pilots a ship through an asteroid field.
- Use arrow keys (or WASD) to steer and space to fire a mining laser at drifting asteroids.
- Mining yields minerals and a small fuel boost, while fuel continuously drains.
- **Lose condition:** fuel reaches 0 or the ship collides with an asteroid.
- Goal: collect a target amount of minerals before losing.
