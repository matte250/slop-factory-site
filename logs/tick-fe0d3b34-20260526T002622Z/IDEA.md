# Game Idea: Asteroid Dodge

**Core**: A spaceship navigates an endless field of falling asteroids on an HTML canvas. Arrow keys move the ship horizontally; floating fuel canisters replenish a constantly draining fuel bar.

**Lose Condition**: The game ends if the ship collides with an asteroid **or** if fuel reaches zero.

**Goal**: Survive as long as possible, earning points for each asteroid avoided and fuel collected.
