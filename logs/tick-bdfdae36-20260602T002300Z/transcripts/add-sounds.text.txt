Added basic sound effects using the Web Audio API:

- **Audio context** with helper functions to play tones for thrust, explosions, and power‑up collection.  
- Integrated sound triggers into:
  * Ship movement (thrust sound on arrow keys)  
  * Collision with asteroids (explosion sound)  
  * Collecting power‑ups (power‑up sound)  

All changes are in `game.js`; the game now provides audible feedback while keeping the existing canvas‑based graphics. Enjoy the enhanced experience!
