Added sound effects using the Web Audio API:

- **Thrust**: plays a short beep when the up‑arrow is pressed.  
- **Collision**: plays a low‑frequency beep on hitting debris.  
- **Fuel collection**: plays a higher‑frequency beep when a fuel cell is gathered.  
- **Game over**: plays a deeper, longer beep when the game ends.  

Implemented an `audioCtx` that resumes on the first key press, and added helper functions (`playThrust`, `playCollision`, `playCollect`, `playGameOver`). Integrated these sounds into the appropriate game events. The rest of the game logic and graphics remain unchanged.
