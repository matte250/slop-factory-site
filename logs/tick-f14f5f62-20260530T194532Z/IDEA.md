# Game Idea: Neon Grid Escape

- **Genre**: Arcade / Reflex
- **Core mechanic**: Control a glowing square navigating an endless scrolling neon grid.
- **Goal**: Survive as long as possible while avoiding randomly spawning spikes and moving laser walls.
- **Lose condition**: The player loses instantly when the square collides with any spike or laser wall, or falls off the bottom of the grid.
- **Canvas friendly**: Simple shapes and animations can be rendered with `requestAnimationFrame` and basic 2D canvas drawing.
