# Game Idea: Falling Blocks Escape

- **Genre:** Endless arcade
- **Controls:** Left/Right arrow keys (or A/D) to move a player square horizontally.
- **Mechanic:** Blocks of varying width spawn at random positions at the top of the canvas and fall down, accelerating over time.
- **Objective:** Survive as long as possible, gaining points for each block that passes the bottom.
- **Lose Condition:** The game ends when a falling block collides with the player square or the player is pushed off the left/right edges.
