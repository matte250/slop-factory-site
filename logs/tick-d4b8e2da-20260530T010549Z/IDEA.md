# Game Idea: Canvas Asteroid Dodge

A simple HTML5 canvas game where the player pilots a small ship that continuously moves forward through an endless field of randomly generated asteroids.

- **Controls:** Arrow keys or WASD to steer left/right and up/down.
- **Goal:** Survive as long as possible while the ship automatically accelerates.
- **Lose Condition:** The ship collides with any asteroid, ending the game.
- **Scoring:** Distance traveled (or time survived) is displayed as the score.
- **Visuals:** Minimalist vector graphics; asteroids are drawn as rotating polygons.

The core mechanics involve basic collision detection and procedural generation, both easily implementable with the canvas API.
