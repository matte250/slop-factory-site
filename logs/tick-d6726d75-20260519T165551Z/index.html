# Game Idea: Neon Runner

A minimalist endless‑runner rendered on an HTML canvas.

- **Gameplay**: A glowing square moves automatically forward. The player can jump over or slide under neon obstacles that appear from the right.
- **Controls**: Space (or up arrow) to jump, down arrow to slide.
- **Lose condition**: Colliding with any obstacle or falling off the bottom edge ends the game.
- **Goal**: Survive as long as possible; score is based on distance traveled.

function beep(freq, duration) {
  // Ensure AudioContext is running (required after user interaction)
  if (audioCtx.state !== 'running') audioCtx.resume();
  const osc = audioCtx.createOscillator();
  const gain = audioCtx.createGain();
  osc.type = 'sine';
  osc.frequency.value = freq;
  osc.connect(gain);
  gain.connect(audioCtx.destination);
  gain.gain.setValueAtTime(0.1, audioCtx.currentTime);
  osc.start();
  osc.stop(audioCtx.currentTime + duration);
}
