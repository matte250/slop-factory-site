Implemented **game.js** with a complete, functional “Space Survivor” arcade game:

- Targets the `<canvas id="game">` element.
- Handles ship rotation, thrust, simple physics, and friction.
- Spawns and moves asteroids from random edges.
- Detects collisions and out‑of‑bounds loss conditions.
- Updates and displays score, and shows “Game Over” when appropriate.
- Runs an animation loop using `requestAnimationFrame`.

The game is ready to be linked from the existing HTML page.
