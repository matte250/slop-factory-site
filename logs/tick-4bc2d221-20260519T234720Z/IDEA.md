# Game Idea: Canvas Runner

A simple endless runner implemented on an HTML canvas. The player controls a character that automatically moves forward across a scrolling landscape. Random obstacles such as spikes, gaps, and low-hanging barriers appear. The player can tap/click to **jump** or **slide** to avoid them.

**Lose condition:** The game ends when the character collides with an obstacle or falls into a gap.

**Goal:** Survive as long as possible; the score is the distance traveled.
