Added auditory feedback while keeping the existing gameplay:

- Created an **AudioContext** and a reusable `beep(freq, duration)` helper.
- Resumes the audio context on the first key interaction (required by browsers).
- Plays a short low‑frequency beep when the player collects a coin.
- Plays a longer low‑frequency beep when the player collides with an orb (game‑over).

All sound handling is lightweight, uses the Web Audio API, and integrates seamlessly with the existing canvas logic.
