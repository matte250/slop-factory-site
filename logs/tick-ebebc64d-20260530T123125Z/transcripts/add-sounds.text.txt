Implemented audio feedback:

- Added an `AudioContext` manager and helper `playTone`.
- Defined specific sound functions: **shoot**, **capture**, **explosion**, **game‑over**.
- Triggered sounds at appropriate points:
  - Shooting (space bar) → `playShoot()`
  - Successful junk capture → `playCapture()`
  - Debris hitting the bottom or colliding with the ship → `playExplosion()`
  - Timer runs out → `playGameOver()`

All sound logic lives in the same script, activated only after a user interaction, preserving the existing game flow while enriching the experience with audio cues.
