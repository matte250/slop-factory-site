```
# Canvas Asteroid Dodge

- Player controls a small ship at the bottom of the canvas with left/right arrows.
- Asteroids spawn at random positions at the top and fall down at varying speeds.
- The ship must dodge the falling asteroids; each successful dodge increments the score.
- **Lose condition:** The game ends instantly when an asteroid collides with the ship.
- Simple geometry (circles, rectangles) makes it easy to implement using only the HTML canvas API.
```
