Added audio to the game:

- Created an `AudioContext` and a simple `playBeep` helper for one‑shot sounds.
- Added a low‑level background “drone” that starts on the first user click and stops when the player crashes.
- Played a subtle beep each time an asteroid spawns.
- Played a louder beep (and stopped the drone) on collision/game‑over.

All sound effects are generated with the Web Audio API and are triggered automatically during gameplay.
