# Game Idea: **Asteroid Escape**

- **Genre:** Arcade, endless runner
- **Controls:** Mouse or arrow keys to steer a spaceship on a HTML canvas.
- **Objective:** Survive as long as possible by dodging randomly spawning asteroids.
- **Lose Condition:** The game ends when the ship collides with any asteroid.
- **Score:** Distance traveled or time survived, displayed on-screen.
- **Visuals:** Simple vector graphics with parallax starfield background.

A compact, easy‑to‑implement canvas game with a clear losing condition.
