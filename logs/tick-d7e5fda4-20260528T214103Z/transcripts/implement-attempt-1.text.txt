Implemented **game.js** with a concise Meteor Dodge game targeting the HTML `<canvas id="game">`. The script:

- Sets up canvas and drawing context.
- Handles player ship movement (left/right) and optional shield power‑up.
- Spawns and animates falling meteors that speed up over time.
- Includes occasional shield power‑ups.
- Tracks a 60‑second timer (lose on collision or time out).
- Provides simple collision detection, game‑over overlay, and a timer bar.

Add this file to the page and include it with `<script src="game.js"></script>` to run the game.
