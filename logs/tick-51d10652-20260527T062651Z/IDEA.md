# Game Idea: Canvas Dodge

**Concept**: A simple HTML canvas game where the player controls a square at the bottom of the screen, moving left and right to dodge falling circles.

**Goal**: Survive as long as possible while the circles fall faster.

**Lose Condition**: The player loses if a falling circle collides with the player square.

**Key Features**:
- Arrow keys or mouse for horizontal movement.
- Gradually increasing spawn rate and speed of circles.
- Score based on survival time.
- Minimalist pixel art style, suitable for a single HTML canvas.
