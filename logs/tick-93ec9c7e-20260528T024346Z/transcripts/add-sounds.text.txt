Implemented sound effects:

- Created an **AudioContext** and a reusable `playTone(freq, duration)` helper.
- Added a listener to resume the audio context on any key press (required for browsers that block autoplay).
- Played a short tone when:
  - The shield power‑up spawns.
  - The ship’s shield destroys an asteroid.
  - An asteroid is spawned.
  - The game ends (game‑over tone).

These additions enrich the gameplay experience while keeping the code concise.
