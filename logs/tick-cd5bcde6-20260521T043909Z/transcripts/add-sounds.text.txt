Implemented audio feedback:

- Initialized a Web Audio API context and helper functions `playBeep` and `playSound`.
- Added `playSound('shoot')` on bullet fire.
- Added `playSound('explosion')` when a bullet destroys an asteroid.
- Added `playSound('pickup')` when the ship collects fuel.
- Added `playSound('gameover')` on ship‑asteroid collision.
- Ensured the audio context resumes on the first key press. 

These sound cues complement the improved graphics for a richer game experience.
