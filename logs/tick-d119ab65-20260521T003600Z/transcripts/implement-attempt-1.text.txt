Implemented **Space Dodger** game in `game.js`. The script:

- Targets the canvas with `id="game"`.
- Handles responsive resizing.
- Provides player ship movement via arrow/WASD keys.
- Generates scrolling asteroid obstacles with increasing speed.
- Detects collisions, ends the game with a “Game Over” overlay.
- Shows a running survival‑time score.

Add this file to your project; the existing HTML canvas will render the game automatically.
