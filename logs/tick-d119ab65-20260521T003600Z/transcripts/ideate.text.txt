# Game Idea: Space Dodger

**Concept**: A top‑down shooter where the player pilots a small spaceship that constantly moves forward. Asteroids and debris drift in from the top of the canvas. The player uses arrow keys (or WASD) to steer left/right and boost up/down to dodge.

**Lose Condition**: The game ends when the ship collides with any asteroid or debris. A brief “Game Over” overlay appears.

**Core Mechanics**:
- Continuous scrolling background.  
- Simple sprite rendering on the HTML canvas.  
- Randomly generated obstacles with increasing speed.  
- Score based on survival time.

**Why it’s feasible**: Only requires canvas drawing, basic keyboard input, and a game loop – all straightforward in vanilla JavaScript.
