Implemented **Canvas Escape** game in `game.js`:

- Targets `<canvas id="game">` and sets up a 400×600 drawing area.  
- Implements ship physics with gravity and upward boost on click/tap.  
- Generates scrolling obstacle rectangles at regular intervals.  
- Handles collision detection, game‑over overlay, and restart on click.  
- Tracks and displays elapsed time as the score.  

The game runs automatically when the script is loaded. Use the existing HTML canvas to see it in action.
