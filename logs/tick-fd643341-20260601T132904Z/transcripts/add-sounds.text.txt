Added a full audio system to **Neon Runner**:

- Created a reusable `AudioContext` with resume handling on the first user interaction.  
- Implemented `playTone` for jump, slide, and crash sound effects.  
- Added background music (low‑frequency hum) that starts after the first key press or pointer down.  

All changes are in `game.js`, targeting the `<canvas id="game">` element. The game now features immersive sound effects and a subtle ambient track.
