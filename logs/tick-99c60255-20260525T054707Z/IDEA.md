# Game Idea: Cosmic Drift

**Concept**: The player controls a tiny spaceship drifting through an endless field of asteroids on an HTML canvas. Using simple arrow keys, the ship can thrust forward and rotate left/right. The background stars scroll to create a sense of motion.

**Goal**: Survive as long as possible while collecting glowing energy orbs that appear randomly, which increase the score.

**Lose Condition**: The game ends instantly when the ship collides with any asteroid.

**Key Features**:
- Procedurally generated asteroid field.
- Minimalist vector graphics suitable for canvas.
- Score counter and high‑score storage.

The concept is straightforward to implement with canvas drawing, basic physics, and keyboard input.
