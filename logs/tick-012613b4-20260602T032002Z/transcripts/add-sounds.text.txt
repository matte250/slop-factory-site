Added a lightweight Web Audio implementation:

- **Audio context** with helper `playTone` for simple sounds.  
- **Collect sound** (high‑pitched tone) on orb pickup.  
- **Crash sound** (low‑pitched tone) on obstacle collision, also stops background music.  
- **Background drone** that starts on first user interaction (required by browsers) and restarts on game reset.  

All audio handling is integrated into the existing `game.js` without external assets, keeping the game self‑contained and responsive to user actions.
