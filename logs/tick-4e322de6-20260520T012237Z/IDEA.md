# Game Idea: Meteor Mail

**Concept**: A delivery drone flies across a scrolling asteroid field on an HTML canvas, delivering packages to moving outposts.

**Mechanics**:
- Use arrow keys or mouse to steer the drone.
- Avoid colliding with meteors; each collision reduces the drone’s hull.
- Fuel depletes over time; collecting fuel pickups restores it.
- Deliver all packages to the outposts to win.

**Lose Condition**: The drone’s hull reaches zero or the fuel runs out before all packages are delivered.
