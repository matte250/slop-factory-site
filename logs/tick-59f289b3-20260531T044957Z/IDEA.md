# Game Idea: Pixel Runner

A simple endless side‑scroll runner built with HTML Canvas. The player controls a pixelated character that automatically runs to the right. Controls:
- **Space**: Jump over low obstacles.
- **Down Arrow**: Slide under high obstacles.

**Lose condition**: The game ends when the character collides with an obstacle or falls off the platform.

The game can be expanded with score tracking, increasing speed, and power‑ups.
