# Game Idea: Neon Runner

A simple endless‑runner where the player pilots a neon ship scrolling horizontally across a star‑filled canvas. The ship can move up and down to dodge randomly generated obstacles (asteroids, laser barriers) and collect power‑ups for points. **Lose condition:** the ship has a health bar that decreases on each collision; the game ends when health reaches zero.

The game can be built with HTML5 Canvas, using `requestAnimationFrame` for the game loop, basic rectangle/circle collision detection, and keyboard input for vertical movement.
