Implemented **game.js** with a functional Asteroid Escape canvas game:

- Targets the canvas element with `id="game"`.
- Handles ship movement, rotation, thrust, and fuel consumption.
- Spawns and animates asteroids, includes screen wrapping.
- Detects collisions and fuel depletion to trigger game over.
- Displays fuel UI and end‑game message.
- Manages keyboard input for controls.
