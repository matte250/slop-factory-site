# Canvas Runner Idea

A side‑scrolling endless runner on an HTML canvas. The player controls a character that automatically moves forward; using tap/space they can jump to avoid randomly generated obstacles (spikes, gaps, moving blocks). The game ends (lose condition) when the character collides with an obstacle or falls off the bottom of the canvas.

**Key Features**
- Simple controls (single key/tap for jump).
- Procedurally generated obstacle patterns.
- Score based on distance traveled.
- Simple graphics drawn with canvas shapes.
