# Game Idea: Asteroid Escape

**Genre:** Endless runner / arcade
**Controls:** Arrow keys (or WASD) to steer a spaceship.
**Objective:** Fly through an endless field of moving asteroids, collecting occasional power‑ups for speed or shield.
**Lose Condition:** The game ends immediately when the spaceship collides with any asteroid.
**Visuals:** Simple shapes on an HTML canvas—ship as a triangle, asteroids as rotating polygons.

*The core loop can be implemented with `requestAnimationFrame`, handling input, drawing, and collision detection.*
