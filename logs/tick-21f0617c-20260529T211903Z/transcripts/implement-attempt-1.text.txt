Implemented a concise **game.js** that creates an endless‑runner “Asteroid Escape” based on the IDEA.md description.

Key points:
- Targets the canvas with `id="game"`.
- Handles keyboard input (arrow keys/WASD) to move a triangular ship.
- Spawns rotating polygon asteroids that scroll from right to left.
- Performs simple circle‑based collision detection; ends the game with “Game Over” when the ship hits an asteroid.
- Uses `requestAnimationFrame` for the game loop, updating positions, drawing the ship and asteroids, and keeping the ship within canvas bounds.
