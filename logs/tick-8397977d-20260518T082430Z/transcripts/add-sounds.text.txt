Added Web Audio support and sound effects:

* Initialized an `AudioContext` with resume handling on first key press.  
* Implemented `playLaser()` for firing, using a short square‑wave oscillator.  
* Implemented `playExplosion()` for asteroid destruction, using a brief noise burst.  
* Integrated `playLaser()` into the space‑bar firing logic.  
* Integrated `playExplosion()` into the projectile‑asteroid collision handling.  

All enhancements are in `game.js`; the game now plays a laser tone when firing and an explosion sound when an asteroid is hit, while preserving existing mechanics and graphics.
