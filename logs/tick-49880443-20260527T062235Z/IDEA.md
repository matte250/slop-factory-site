# Game Idea: Asteroid Dodge

**Genre:** Arcade / Endless runner

**Core Loop:**
- Player controls a small spaceship that constantly moves forward across a star‑filled background on an HTML canvas.
- Asteroids of varying size and speed appear from the right and move leftwards.
- Use arrow keys (or tap) to move up/down (or thrust) to dodge the asteroids.

**Lose Condition:**
- The game ends when the spaceship collides with any asteroid.

**Win Condition (optional):**
- Survive as long as possible; high‑score based on time or distance.

**Why it works on Canvas:**
- Simple sprite drawing and collision detection using pixel positions.
- Minimal assets; can be built with pure JavaScript and canvas 2D API.
