# Random HTML Canvas Game Idea

**Title:** *Glitch Runner*

**Concept:** The player controls a pixel‑art runner that automatically scrolls through a glitch‑filled corridor. The player can jump or slide to avoid glitch obstacles (spikes, gaps, flickering walls) that appear randomly.

**Controls:**
- Space / Up Arrow – jump
- Down Arrow – slide

**Goal:** Survive as long as possible while collecting glowing data packets for points.

**Lose Condition:** Colliding with any glitch obstacle (spike, wall, or falling into a gap) ends the game.

**Unique Twist:** The background slowly desynchronizes, causing occasional visual “glitch” events that temporarily invert controls, adding a timing challenge.
