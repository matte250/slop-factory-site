Implemented **Pixel Dodger** in `game.js`:

- Targets the existing `<canvas id="game">`.
- Handles player movement via arrow keys.
- Spawns green (score) and red (danger) squares that fall from the top.
- Detects collisions: green squares increase score, red squares end the game.
- Ends the game if any shape reaches the bottom.
- Displays current score and a “Game Over” overlay.

Add this script to the HTML page to activate the game.
