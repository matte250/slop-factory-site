Added sound effects:

- Created an `AudioContext` and reusable `playTone(freq, duration)` helper.
- Jump now plays a high‑pitched tone (600 Hz, 0.1 s) and resumes the audio context on the first user gesture.
- Collision now plays a low‑pitched tone (200 Hz, 0.3 s) before triggering game over.

All changes are in **game.js** and integrate with the existing game loop.
