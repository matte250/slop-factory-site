Added simple sound effects using the Web Audio API:

* Created an `audioCtx` with helper functions `playTone`, `playSpawnSound`, and `playCollisionSound`.
* Played a short tone when each asteroid spawns.
* Played a descending‑pitch “explosion” sound when a collision ends the game.

All audio code lives in `game.js`; no changes to HTML are required. The canvas with `id="game"` remains the target for rendering.
