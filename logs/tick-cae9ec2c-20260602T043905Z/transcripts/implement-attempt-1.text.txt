Implemented **game.js**:

- Targets `<canvas id="game">`.
- Sets canvas dimensions to viewport size.
- Handles ship movement via arrow keys (or A/D).
- Spawns random debris each second, updates and removes off‑screen pieces.
- Detects collisions; on hit displays “Game Over”.
- Tracks survival time as score and displays it.
- Runs an animation loop with `requestAnimationFrame`.
