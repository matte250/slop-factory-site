# Game Idea: Meteor Dodge

- **Genre:** Arcade  
- **Core mechanic:** Player controls a ship at the bottom of a canvas, moving left/right to dodge falling meteors.  
- **Controls:** Arrow keys or mouse.  
- **Goal:** Survive as long as possible, earning points for each meteor avoided.  
- **Lose condition:** The game ends when a meteor collides with the ship or the player runs out of lives.  

This concept is suitable for implementation with a single HTML `<canvas>` and vanilla JavaScript.
