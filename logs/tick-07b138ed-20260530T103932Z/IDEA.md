# Game Idea: Asteroid Dodge

- **Genre:** Endless arcade / avoidance
- **Mechanic:** Control a ship that moves horizontally across the canvas. Asteroids spawn at the top and fall with increasing speed.
- **Goal:** Dodge as many asteroids as possible to rack up a high score.
- **Lose condition:** The game ends instantly when the ship collides with any asteroid.
- **Canvas use:** Simple shape drawing, sprite animation, and collision detection via `requestAnimationFrame`.
