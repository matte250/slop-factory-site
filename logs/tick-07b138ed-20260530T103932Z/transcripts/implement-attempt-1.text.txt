Implemented **`game.js`** with a concise Asteroid Dodge game:

- Targets canvas `id="game"` and resizes it.
- Handles ship movement (arrow keys / A D).
- Spawns and updates falling asteroids, increasing speed with score.
- Performs collision detection and ends the game on impact.
- Displays live score and a “Game Over” overlay.

The file is ready to be referenced by the existing HTML page.
