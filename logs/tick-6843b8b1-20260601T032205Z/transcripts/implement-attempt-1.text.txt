Implemented **game.js** with a complete “Asteroid Dodge” game:

- Targets the canvas element with `id="game"`.
- Handles ship movement via arrow keys.
- Spawns and animates asteroids that increase in speed over time.
- Detects collisions, ends the game on impact, and displays a “Game Over” overlay.
- Shows a running score counter.

The script is self‑contained and ready to run with the existing HTML canvas.
