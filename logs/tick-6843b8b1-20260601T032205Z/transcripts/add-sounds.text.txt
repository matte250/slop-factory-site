Implemented sound effects using the Web Audio API:

- **Audio context & `playTone` helper** added for generating simple tones.
- **Movement tones**: each arrow‑key press now plays a 440 Hz beep.
- **Asteroid spawn tone**: a subtle 220 Hz beep when a new asteroid appears.
- **Collision tone**: a 660 Hz beep when the ship hits an asteroid.
- Ensured the audio context resumes on the first user interaction (keydown).

All changes are in **game.js**; the game now provides audible feedback for navigation, hazards, and collisions while preserving existing gameplay.
