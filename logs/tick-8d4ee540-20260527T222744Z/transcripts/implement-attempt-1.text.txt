Implemented **`game.js`**:

- Targets canvas element with id **`game`**.
- Minimal endless runner:
  - Player square can **jump** (Space) and **slide** (Down arrow).
  - Random spikes and gaps appear as obstacles.
  - Collision detection ends the game and shows **Game Over** with score.
  - Speed gradually increases; score reflects distance traveled.
- Uses `requestAnimationFrame` for smooth animation and updates.

Add the script to your HTML page (e.g., `<script src="game.js"></script>`) to run the game.
