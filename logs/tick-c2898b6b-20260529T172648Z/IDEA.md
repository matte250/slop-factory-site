# Game Idea: Asteroid Evader

- **Genre:** Simple arcade dodging game (HTML canvas)
- **Controls:** Arrow keys or mouse to rotate ship and thrust forward
- **Gameplay:** Asteroids spawn at random positions on the canvas edges and travel in straight lines across the screen. The player must maneuver the ship to avoid collisions while the ship drifts due to inertia.
- **Scoring:** Points accumulate over time survived, optionally increasing speed of asteroid spawn.
- **Lose Condition:** The game ends instantly when the ship collides with any asteroid.
- **Visuals:** Minimalist vector graphics; ship as a triangular shape, asteroids as circles or polygons.

This concept can be implemented with plain JavaScript and the HTML `<canvas>` element, requiring only basic physics and collision detection.
