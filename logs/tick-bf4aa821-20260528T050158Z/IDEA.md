# Game Idea: Orbital Dodge

- **Core mechanic**: Player controls a small spacecraft orbiting a central planet using left/right arrow keys to rotate and up/down keys to change orbital radius.
- **Obstacles**: Asteroids spawn from the edges of the canvas and travel in straight lines toward the planet, forming moving hazards the ship must dodge.
- **Goal**: Survive as long as possible, racking up time or score while navigating the orbit.
- **Lose condition**: The game ends immediately if the spacecraft collides with any asteroid or crashes into the planet.

*Simple graphics and physics make it ideal for an HTML `<canvas>` implementation.*
