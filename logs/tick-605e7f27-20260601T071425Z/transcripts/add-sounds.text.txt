Added sound effects using the Web Audio API:

- Initialized an `AudioContext` and resumed it on first user interaction.
- Created helper `playTone` for generating simple tones.
- Added specific sound functions:
  - `playBoost()` on boost activation.
  - `playCollect()` when a fuel cell is collected.
  - `playCollision()` on collision (game over).

Integrated these calls into the game loop and collision/collection logic. The game now has audible feedback for key actions while preserving existing graphics improvements.
