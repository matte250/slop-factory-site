# Random Canvas Game Idea

**Title:** Pixel Runner

**Concept:** An endless runner where a pixel character runs across a side‑scrolling canvas, jumping over randomly generated obstacles. The background scrolls automatically; the player can tap/press space to jump.

**Lose Condition:** The game ends if the player collides with an obstacle or falls off the bottom of the canvas.

**Goal:** Survive as long as possible, with score based on distance.
