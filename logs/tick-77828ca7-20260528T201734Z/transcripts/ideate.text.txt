# Game Idea: Asteroid Dodge

- Player controls a small ship moving left/right on a canvas.  
- Asteroids spawn from the top and fall at increasing speed.  
- Goal: survive as long as possible; score is time survived.  
- **Lose condition:** the ship collides with any asteroid.  

The concept is simple to implement using HTML canvas and keyboard input.
