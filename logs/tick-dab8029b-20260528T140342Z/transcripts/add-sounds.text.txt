Added Web Audio API support:

- Created `audioCtx` and helper functions `playTone`, `playLaserSound`, `playExplosionSound`, `playGameOverSound`.
- Triggered laser sound on firing, explosion sound on asteroid hit, and a low‑tone game‑over sound.
- Resumed the audio context on the first key press so sounds can play.

All audio logic is integrated directly in `game.js` without external files, keeping the game self‑contained.
