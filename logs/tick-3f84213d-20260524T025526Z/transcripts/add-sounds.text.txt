Added a simple sound system using the Web Audio API:

* Initialized an `AudioContext` on the first key press.
* Created `playTone(freq, duration)` to emit short sine‑wave tones.
* Triggered a boost tone (500 Hz, 0.1 s) when the **ArrowUp** key is pressed.
* Played a collision tone (200 Hz, 0.3 s) when the ship hits an asteroid.

All other game logic and graphics remain unchanged. The game now has auditory feedback for boosting and collisions.
