Added sound effects using the Web Audio API:

- **Thrust**: plays a short tone when the space bar is pressed.  
- **Collision**: plays a lower‑frequency tone when the ship hits an asteroid.  
- **Pickup**: plays a higher‑frequency tone when a fuel pickup is collected.  

Implemented an `audioCtx` and helper `playTone` function; integrated sound triggers in the appropriate input and collision handling sections. The game now provides audible feedback for key actions while keeping the visual improvements unchanged.
