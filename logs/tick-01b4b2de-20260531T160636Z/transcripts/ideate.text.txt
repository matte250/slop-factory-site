# Game Idea: *Orbit Escape*

- **Genre**: Action / Arcade  
- **Platform**: HTML5 Canvas (pure JavaScript)  
- **Core mechanic**: Player controls a ship rotating around a central planet, thrusting outward while dodging asteroids.  
- **Goal**: Survive as long as possible, collecting fuel pickups to stay alive.  
- **Lose condition**: Collision with an asteroid or running out of fuel ends the game.  
- **Visuals**: Simple vector shapes (planet circle, ship triangle, asteroid circles).  
- **Scoring**: Time survived (seconds) and fuel pickups collected.  

The idea is implementable with a single HTML file using the Canvas API, `requestAnimationFrame`, and basic physics.
