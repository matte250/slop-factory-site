Implemented richer graphics for **Asteroid Run**:

* Added a dark gradient background with a static starfield.
* Created a pre‑generated `stars` array for twinkling points.
* Enhanced the ship drawing with an outline.
* Added rotation and irregular polygon rendering for asteroids, including per‑asteroid rotation state.
* Updated the asteroid update loop to advance rotation each frame.
* Replaced the plain shield bar with a gradient‑filled bar on a dark background.

These changes give the game a deeper space feel, more dynamic asteroid visuals, and a clearer UI while keeping the core gameplay intact.
