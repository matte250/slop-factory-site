```
# Game Idea: Asteroid Run

**Concept**: A top‑down endless runner where the player pilots a tiny spaceship through an asteroid field.

**Controls**: Arrow keys (or WASD) to rotate and thrust.

**Goal**: Survive as long as possible while collecting occasional energy pickups to boost score.

**Lose Condition**: The ship has a single shield meter; colliding with an asteroid reduces the shield. When the shield reaches zero, the game ends.

**Why Canvas?**: Simple 2‑D sprite rendering, collision detection and continuous scrolling are straightforward with the HTML `<canvas>` API.
```
