Added audio feedback using the Web Audio API:

* Created an `AudioContext` with a reusable `beep(freq, duration)` helper.
* Played a short beep for:
  * asteroid‑ship collisions (200 Hz)
  * package collection (800 Hz)
  * game‑over (150 Hz)
* Ensured the audio context resumes after the first user click.

All changes are in **game.js**, enhancing the game with simple sound effects while keeping the existing graphics and logic intact.
