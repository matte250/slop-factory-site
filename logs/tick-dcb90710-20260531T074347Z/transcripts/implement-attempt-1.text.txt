Implemented a concise **Asteroid Dodge** game in `game.js` that targets the canvas with `id="game"`.

Key features:
- Player ship moves left/right via arrow keys.
- Asteroids spawn from the top, speed up over time, and are removed when off‑screen.
- Simple rectangle‑circle collision detection ends the game.
- Score displayed (seconds survived) and a game‑over overlay.

The script automatically adjusts canvas size, handles input, updates game state, and renders each frame. Include this file in your HTML page that contains `<canvas id="game"></canvas>`.
