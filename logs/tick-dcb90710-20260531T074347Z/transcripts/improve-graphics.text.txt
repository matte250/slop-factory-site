Implemented richer visuals for the Asteroid Dodge game:

* Added a dark gradient background with moving starfield.
* Ship is now rendered as a blue triangle.
* Asteroids now have radial shading and rotate as they fall.
* Updated asteroid data structure to include rotation properties.
* Integrated star movement into the update loop.

All changes are in `game.js`, targeting the existing `<canvas id="game">`. The game will now display a more polished, space‑themed look while preserving the original gameplay.
