# Game Idea: Cosmic Dodge

**Genre:** Endless runner / arcade  

**Canvas Mechanics:** The player controls a small ship that moves up and down using the arrow keys (or mouse). Asteroid-shaped obstacles spawn from the right and move left across the canvas.  

**Goal:** Survive as long as possible and rack up points based on time and obstacles passed.  

**Lose Condition:** The game ends instantly when the ship collides with any asteroid.
