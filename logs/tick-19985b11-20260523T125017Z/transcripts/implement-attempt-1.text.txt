Implemented **Asteroid Escape** game in `game.js` targeting the canvas with `id="game"`.

Key features:
- Ship navigation with rotation, thrust, and fuel consumption (arrow keys).
- Shooting with Spacebar, bullets destroy asteroids.
- Randomly spawning asteroids and fuel pickups.
- Collision detection, fuel bar, and survival timer.
- Game over on collision or out‑of‑fuel.

The HTML canvas (`<canvas id="game">`) will now run the full game when `game.js` is included.
