Added lightweight sound effects using the Web Audio API:

* Created an `AudioContext` and a reusable `playSound()` helper.
* Played a short laser sound on each shot.
* Played an explosion sound when an asteroid is destroyed.
* Ensured the audio context resumes after user interaction.

All changes are in **`game.js`** and integrate with the existing canvas (`id="game"`). Enjoy the new audio feedback!
