Added audible feedback:

- Created an `AudioContext` with a reusable `playBeep(freq, duration)` helper.
- Added a subtle low‑hum background oscillator.
- Played a short beep each time a new asteroid spawns.
- Played a low‑pitch beep on ship‑asteroid collision.
- Resumed the audio context on any key press so browsers that block autoplay can initialise audio.

All sounds are generated with the Web Audio API, keeping the game self‑contained and lightweight.
