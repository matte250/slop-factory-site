Implemented sound effects with the Web Audio API:

- Added audio context, tone‑playing helper, and specific `playCollision` / `playSpawn` functions.  
- Background hum starts automatically and stops on collision.  
- Meteor spawn triggers a brief tone.  
- Collision triggers a low‑frequency “boom” and stops the background music.  
- Resumes audio context on first player input to satisfy browsers that block autoplay.  

All changes are in `game.js`; the game now has auditory feedback while keeping the same gameplay.
