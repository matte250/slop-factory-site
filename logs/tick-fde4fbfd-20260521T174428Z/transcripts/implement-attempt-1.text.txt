Implemented **game.js** with a concise Meteor Dodge game:

- Targets the canvas with `id="game"`.
- Handles player movement (arrow keys / A‑D).
- Spawns falling meteors at random positions and speeds.
- Detects collisions with a simple AABB check.
- Shows a “Game Over” overlay when the ship is hit.
- Uses an animation loop via `requestAnimationFrame`.

The file is ready to be linked from the HTML page.
