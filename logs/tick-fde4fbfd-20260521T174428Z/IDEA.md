# Game Idea: Meteor Dodge

- **Genre:** Arcade / Endless runner  
- **Core mechanic:** Player controls a spaceship moving left/right at the bottom of an HTML canvas. Meteors spawn at random positions at the top and fall with varying speeds. The player must dodge them.
- **Lose condition:** The game ends immediately when the spaceship collides with any meteor.
- **Optional twist:** Power‑ups appear occasionally to grant temporary shields or speed boosts.

This concept fits within a single HTML canvas file and can be built with vanilla JavaScript.
