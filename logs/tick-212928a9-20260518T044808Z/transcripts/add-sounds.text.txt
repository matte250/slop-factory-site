**Added sound effects**

- Created an `AudioContext` with helper functions (`beep`, `playBoost`, `playCollect`, `playCollision`, `playGameOver`).
- Resumes audio on first user interaction.
- Added a `prevBoost` flag to detect boost start and play a boost beep.
- Played collection sound when a package is collected.
- Played collision sound on first asteroid hit and a distinct game‑over sound when fuel runs out.
- Introduced `soundFlags` to ensure each sound (collision, game over) triggers only once.  

The game now provides auditory feedback for key actions while keeping the existing gameplay and graphics unchanged.
