Implemented **`game.js`** – a concise endless‑runner using the canvas with id `game`.

Key features:
- Player square can **jump** (`ArrowUp`) and **slide** (`ArrowDown`).
- Random obstacles scroll left; collision ends the game.
- Score increments as obstacles are passed.
- Simple ground, background, and game‑over overlay.
- Self‑contained IIFE, auto‑starts with `requestAnimationFrame`.

Add the script to the HTML page containing `<canvas id="game"></canvas>` to run the game.
