# Game Idea: Canvas Asteroid Dodger

A minimalist top‑down HTML canvas game where the player controls a spaceship navigating an endless field of moving asteroids. The ship can rotate and thrust using arrow keys. Asteroids drift in random directions and speeds. The player must avoid collisions; touching any asteroid ends the game (lose condition). A timer counts how long the player survives, encouraging high‑score runs. Simple graphics, physics, and a single lose condition keep implementation lightweight.
