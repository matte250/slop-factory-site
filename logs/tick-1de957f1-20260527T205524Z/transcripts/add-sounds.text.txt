Implemented audio for **Canvas Escape**:

* **Audio context** created and resumed on user interaction.
* Helper functions `playTone`, `playCollision`, and `playGameOver` generate simple sine‑tone effects.
* Collision now triggers a short collision sound.
* Game‑over screen plays a distinct low‑frequency tone once.
* Added `gameOverPlayed` flag to avoid repeated game‑over sounds.

All existing mechanics remain unchanged; the game now provides auditory feedback for key events.
