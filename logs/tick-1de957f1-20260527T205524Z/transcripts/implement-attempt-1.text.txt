Implemented **Canvas Escape** as a minimal endless‑runner in `game.js`.  
The script:

* Targets the `<canvas id="game">` element.  
* Handles player movement with arrow keys.  
* Generates rotating rectangular obstacles with gaps.  
* Detects collisions, updates score, and shows a game‑over overlay.  

Add this file alongside the existing HTML; the game will start automatically.
