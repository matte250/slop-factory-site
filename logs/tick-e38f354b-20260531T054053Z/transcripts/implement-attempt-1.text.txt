Implemented **game.js** with a minimal “Cosmic Dodger” game:

- Targets the canvas element `#game`.
- Handles ship movement via arrow keys.
- Spawns drifting asteroids from random edges.
- Detects collisions → game over.
- Tracks score for avoided asteroids.
- Renders ship, asteroids, score, and a game‑over overlay.

The file is ready to be included in the HTML page. Enjoy!
