# Canvas Dodge

Control a spaceship that moves left and right on an HTML canvas. Asteroids fall from the top, speeding up over time. Colliding with an asteroid costs a life. The player starts with three lives and loses the game when all lives are lost. Score increases for each asteroid avoided.
