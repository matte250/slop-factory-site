Implemented **Space Dodger** game in `game.js`:

- Targets canvas with `id="game"` and makes it full‑screen.
- Adds ship (triangle) with arrow/WASD controls.
- Spawns moving asteroids, handles update/draw cycles.
- Collision detection ends the game and shows final score.
- Displays live score based on survival time.

The file is ready to be included by the existing HTML page.
