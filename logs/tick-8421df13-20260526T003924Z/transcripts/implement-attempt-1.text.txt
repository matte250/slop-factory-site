Implemented **Astro Escape** game in `game.js`:

- Targets canvas with `id="game"`.
- Handles ship movement (thrust, rotation), screen wrapping, and rendering.
- Spawns, moves, and draws asteroids; includes splitting on collision.
- Detects ship‑asteroid collisions → game over.
- Displays elapsed time as score.

The script runs automatically on page load and animates via `requestAnimationFrame`.
